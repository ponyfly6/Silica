# 只读代码查看器与 Agent

用户在侧栏向 Agent 描述任务，在主窗口打开文件、查找并复制代码。文件树和已打开的标签页跟随磁盘更新。Markdown 预览、语法高亮、行号、小地图和阅读位置恢复继续服务于阅读。

所有项目修改都由 Agent 执行，因此移除了新建、保存、重命名、删除、输入设置和未保存提示。用户直接阅读当前文件，也就无需维护差异视图、基线和每轮项目快照。窗口之间只保留任务租约，同一项目或上下级目录同时只能运行一个任务。停止任务时先清理子进程，再释放租约。仍有进程存活时由用户决定是否释放。

每轮以右对齐的用户消息开始。悬停可复制消息或将原文放回草稿。默认收起的工作记录保留计划、工具调用和中间回复，并显示耗时和工具步数。最后一次工具调用之后的回复以原生块级 Markdown 展示，可以复制原文、单独复制代码或点击项目内的文件链接跳到指定行。权限请求始终在输入框上方。阅读较早的消息时，新内容不会触发自动滚动。

改动摘要按首次出现顺序列出 ACP 的 edit、delete、move 工具报告的最多 500 个项目内路径。行数来自工具 diff；同一工具重发时覆盖，不同工具对同一文件的行数累加。仅有路径或单侧超过 2 MiB、20,000 行时省略未知计数。展开摘要可打开文件。通过 shell 命令做出的更改仍会通过磁盘通知刷新。每个窗口的一次对话最多保留 100 轮。

会话模型保存命令、标题、最新上下文快照、套餐和适配器报告的 Claude 限额，以及每轮的 token、缓存和费用。重新加载同一会话时保留这些数据，新建对话或切换 Agent 时清空。

## Agent 选择与权限模式

窗口共用同一套 ACP v1 传输、会话和时间线实现。输入卡底部可以选择 Codex 或 Claude Code，连接或执行任务期间锁定选择。空闲时切换会断开连接并清空本窗口的对话。新窗口沿用上次选择，两个适配器各自保存可执行文件路径。

Codex 固定使用 `@agentclientprotocol/codex-acp@2.6.0`。启动时设置 `INITIAL_AGENT_MODE=workspace-write`，允许保留 `workspace-write` 或 `read-only`。如果当前模式不在允许范围内，则请求切换至适配器提供的 `workspace-write`。

### Claude Code

`@agentclientprotocol/claude-agent-acp@0.109.0` 需要 Node.js 22 或更高版本，通过 Claude Agent SDK 0.3.328 使用平台对应的 CLI。适配器复用 Claude Code 登录状态，登录过期时在终端运行 `claude` 并登录，再重新连接。

Claude 保留会话已有的 `auto`、`default`、`acceptEdits`、`plan` 或 `dontAsk` 模式。遇到 `bypassPermissions` 或未知模式时，按 `auto`、`acceptEdits`、`default` 的顺序选择适配器提供的第一项。Claude 必须报告当前模式。Codex 会话未提供模式选项时沿用启动时设置的权限。没有合适的回退选项或模式切换未获确认时，连接失败。面板只显示当前 Agent 允许的模式。

在 Silica 启用终端输出扩展时，Claude 的 Bash 工具通过 `terminal_output_delta` 发送输出，并通过 `terminal_exit` 报告退出状态。仅包含文本的工具无需等待终端退出事件。文件编辑沿用同一套工具位置和 diff 路径提取逻辑。[Claude Code 集成记录](claude-acp-integration.md)

## 面板宽度与模型选择

拖动面板左边缘可以调整宽度（300–820 pt），双击恢复默认的 360 pt。窗口变窄时，面板临时收窄，为编辑器保留至少 420 pt；窗口变宽后恢复保存的宽度。

打开面板、在面板中切换 Agent 或新建对话时自动连接。发送按钮旁的菜单分组显示适配器提供的模型和推理档位，权限菜单位于输入卡下方。模型和档位经适配器确认后按 Agent 分别保存。新建或加载会话时先协商权限，再恢复模型，并根据更新后的选项恢复档位。已下架的选项会跳过，恢复偏好失败时在面板中提示，仍可继续对话。

## 输入卡与用量

顶栏显示连接状态和会话标题，齿轮菜单内可查看适配器版本、设置路径或断开连接。输入卡固定在记录下方，原生文本框随内容增长到约八行。Return 或 ⌘Return 发送，Shift-Return 换行；输入法组词时回车只确认候选。输入 @ 使用快速打开的项目索引匹配文件，行首 / 列出会话支持的命令。方向键选择，Return 或 Tab 插入，Esc 收起。

发送时保留草稿原文，普通消息附带工作区说明，斜杠命令直接发送。项目内存在的文件提及作为 ACP 文件链接跟在文本之后。可选择或拖入文件，也可粘贴图片。每次最多 10 项、共 10 MB；图片上限为 5 MB，需适配器支持。支持内嵌上下文时，最多 256 KiB 的文本文件随消息发送，其余文件作为链接。发送失败可保留附件重试。

权限菜单右侧在上下文用量已知时显示进度条。点击可查看上下文容量、模型、本轮输入输出与缓存明细，以及对话中已报告的 token 和费用合计。缓存命中率以缓存读取除以输入、缓存读取和缓存写入之和，缺少字段或分母为零时省略。

## 离线验证

```sh
bash scripts/test-agent.sh
bash scripts/test-agent-workspace.sh
```

第一条验证协议、工具事件和进程清理。第二条构建应用，使用本地适配器验证只读文本、磁盘同步、租约及会话生命周期。
